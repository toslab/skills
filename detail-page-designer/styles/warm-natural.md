# Warm Natural Style

자연에서 영감을 받은 따뜻하고 친근한 디자인 시스템입니다. 유기적인 형태와 자연스러운 컬러로 편안함과 진정성을 전달합니다.

## 브랜드 무드 & 분위기

### 핵심 키워드
- **Organic** (유기적): 자연스럽고 인위적이지 않은
- **Warm** (따뜻한): 친근하고 포근한 느낌
- **Authentic** (진정성 있는): 진실되고 솔직한
- **Calming** (진정시키는): 편안하고 안정적인
- **Sustainable** (지속가능한): 환경 친화적, 책임감 있는

### 감성적 목표
고객이 페이지를 볼 때 느껴야 할 감정:
- "편안하고 안심된다"
- "자연스럽고 진정성 있다"
- "건강하고 좋다"
- "집처럼 편하다"
- "신뢰할 수 있다"

### 피해야 할 요소
- ❌ 인공적이고 차가운 색상
- ❌ 날카롭고 각진 형태
- ❌ 기계적이고 딱딱한 느낌
- ❌ 과도하게 완벽한 정렬
- ❌ 차갑거나 거리감 있는 톤

## 컬러 사용 가이드라인

### 컬러 비율
- **65%**: Cream/Beige (배경, 여백)
- **25%**: Green/Terracotta/Brown (구조, 강조)
- **10%**: Accent Colors (CTA, 특별 강조)

### 자연스러운 조합
- Terracotta + Sage + Cream
- Clay Brown + Dusty Rose + Sand
- Olive + Ocean Blue + Beige

### 접근성
- Clay Brown on Cream: ✅ 7.8:1 (AAA)
- Sage Green on Cream: ✅ 4.6:1 (AA)
- Terracotta on Cream: ✅ 4.2:1 (AA)
- Charcoal Brown on Cream: ✅ 11.2:1 (AAA)

## 타이포그래피

### Display Font (디스플레이 폰트)
**Font Family**: Fraunces 또는 Spectral (세리프, 부드러운)
- **용도**: 히어로 헤드라인, 주요 제목
- **크기**: 48-64px (데스크톱), 32-42px (모바일)
- **무게**: SemiBold (600) 또는 Bold (700)
- **줄간격**: 1.2
- **자간**: -0.01em
- **색상**: Clay Brown, Charcoal Brown
- **특징**: 부드러운 세리프, 손으로 쓴 듯한 온기

**예시**:
```
"Naturally Beautiful"
"자연 그대로의 아름다움"
```

### Heading Font (제목 폰트)
**Font Family**: Karla 또는 DM Sans (부드러운 산세리프)
- **용도**: 섹션 제목, 카테고리명
- **크기 H2**: 32-40px (데스크톱), 24-32px (모바일)
- **크기 H3**: 24-28px (데스크톱), 20-24px (모바일)
- **크기 H4**: 18-22px (데스크톱), 16-20px (모바일)
- **무게**: Medium (500) 또는 SemiBold (600)
- **줄간격**: 1.3
- **자간**: 0em
- **색상**: Clay Brown, Sage Green
- **특징**: 둥글고 친근한 산세리프

**예시**:
```
H2: "Our Story"
H3: "What We Believe"
```

### Body Font (본문 폰트)
**Font Family**: Lora 또는 Noto Serif (부드러운 세리프)
- **용도**: 본문 텍스트, 스토리텔링
- **크기**: 17-19px (데스크톱), 16-18px (모바일)
- **무게**: Regular (400)
- **줄간격**: 1.7-1.8 (편안한 읽기)
- **자간**: 0.01em
- **색상**: Charcoal Brown (#4A4238)
- **최대 너비**: 65-70자
- **특징**: 따뜻하고 읽기 편한 세리프

**대안 (산세리프)**:
- **Font Family**: Nunito Sans 또는 Rubik
- 더 캐주얼하고 현대적인 느낌

**예시**:
```
"We believe in the power of nature to heal and nurture.
Every ingredient is carefully sourced from sustainable
farms, ensuring that what's good for you is also good
for the planet we all share."
```

### Small Text (작은 텍스트)
**Font Family**: Karla 또는 DM Sans (산세리프)
- **용도**: 라벨, 캡션, 메타데이터
- **크기**: 13-15px
- **무게**: Regular (400) 또는 Medium (500)
- **줄간격**: 1.5
- **자간**: 0.03em
- **색상**: Soft Gray (#C4BBB0)
- **대문자**: 자주 사용 (organic, natural 등)

**예시**:
```
"100% ORGANIC"
"Sustainably Sourced"
```

### 타이포그래피 원칙

1. **부드러운 폰트**: 각지지 않은, 둥근 느낌
2. **세리프 + 산세리프 믹스**: 자연스러운 조화
3. **넉넉한 줄간격**: 편안한 읽기
4. **손글씨 느낌** (선택): 특별한 강조에 사용
5. **소문자 선호**: 친근하고 접근하기 쉬운

## 레이아웃 원칙

### 유연한 그리드
- 전통적 12컬럼보다 **유기적 레이아웃**
- 요소들이 자연스럽게 흐름
- 완벽한 정렬보다 편안한 배치

### 여백 규칙

**8px 기반, 유연하게**:
```
XS:    8px
S:     16px
M:     24px
L:     40px
XL:    56px
XXL:   80px
XXXL:  120px
```

### 섹션 구조

**1. Hero Section**
- 높이: 80-100vh
- 배경:
  - 옵션 1: 자연 사진 (숲, 바다, 산 등)
  - 옵션 2: Cream/Sand 그라디언트
  - 옵션 3: 유기적 도형 배경
- 레이아웃: 비대칭 OK (60/40)
- 요소:
  - Display 제목 (왼쪽 정렬 또는 중앙)
  - 짧은 서브타이틀 (편안한 톤)
  - Soft CTA (둥근 버튼)
  - 자연스러운 이미지/일러스트
- 특징: 즉시 편안함을 느끼게

**2. Story Section**
- 레이아웃: 2 컬럼 또는 단일 컬럼
- 요소:
  - 작은 라벨 ("OUR STORY")
  - H2 제목
  - 본문 (스토리텔링)
  - 이미지 (둥근, 자연스러운)
- 배경: Cream 또는 Light Beige

**3. Feature Cards**
- 레이아웃: 3 컬럼 그리드, 약간 비대칭 OK
- 각 카드:
  - 아이콘 (유기적, 손그림 느낌)
  - 제목 (H4)
  - 설명 (본문)
  - 배경: White 또는 Light Beige
  - 라운드: 16-24px (둥글게)
  - 그림자: 부드럽게
- 간격: 20-24px

**4. Visual Content**
- 레이아웃: 이미지와 텍스트 교차
- 이미지:
  - 라운드: 20-32px (매우 둥글게)
  - 자연스러운 사진
  - 오버레이 없음 (원본 유지)
- 텍스트:
  - 제목 + 본문
  - 넉넉한 여백
  - CTA (subtle)

**5. Testimonials**
- 레이아웃: 카드 형식
- 각 후기:
  - 배경: Sand 또는 White
  - 둥근 모서리 (24px)
  - 프로필 사진 (원형, 큼직한)
  - 후기 텍스트 (이탤릭)
  - 이름 + 정보
- 배치: 약간 겹치거나 비대칭

**6. Product/Service Grid**
- 레이아웃: 2-3 컬럼
- 이미지: 둥근, 자연광 사진
- 텍스트: 제품명 + 간단한 설명
- 배경: Cream
- 호버: 부드러운 확대

**7. CTA Section**
- 배경: Sage Green 또는 Terracotta (밝게, 20-30%)
- 레이아웃: 중앙 정렬
- 요소:
  - 제목 (H2, Charcoal Brown)
  - 짧은 설명
  - Primary CTA (대비되는 버튼)
- 장식: 잎사귀, 꽃 등 자연 요소

### 유기적 디자인 원칙

1. **둥근 모서리**: 모든 요소에 라운드 적용
2. **비대칭 허용**: 자연스러운 배치
3. **겹침과 레이어**: 입체감
4. **유기적 도형**: 원, 부드러운 곡선
5. **자연 요소 장식**: 잎, 꽃, 나뭇가지 등

## 애니메이션 & 인터랙션

### 원칙
- **부드럽게**: 급작스럽지 않게
- **자연스럽게**: 실제 자연의 움직임처럼
- **편안하게**: 사용자에게 스트레스 없이

### 타이밍
- **Slow**: 0.5-0.6s - 큰 전환
- **Medium**: 0.3-0.4s - 일반 효과
- **Gentle**: 0.2s - 작은 변화

### Easing
- `ease-out` - 자연스러운 감속
- `cubic-bezier(0.25, 0.46, 0.45, 0.94)` - 부드러운 곡선

### 허용되는 애니메이션
- **Gentle Fade**: 부드러운 등장
- **Slow Slide**: 천천히 위로 (30-40px)
- **Soft Scale**: 미세 확대 (1.0 → 1.03)
- **Float**: 요소가 살짝 떠다님 (매우 subtle)
- **Parallax**: 배경 느리게 스크롤

### 자연스러운 효과
```css
/* Floating Animation */
@keyframes float {
  0%, 100% { transform: translateY(0px); }
  50% { transform: translateY(-10px); }
}

.floating-element {
  animation: float 4s ease-in-out infinite;
}

/* Gentle Fade In */
@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(40px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.fade-in {
  animation: fadeInUp 0.8s ease-out;
}
```
