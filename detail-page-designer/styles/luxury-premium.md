# Luxury Premium Style

프리미엄 브랜드와 고급 제품을 위한 럭셔리한 디자인 시스템입니다. 절제된 우아함과 세련된 디테일로 최상급 가치를 전달합니다.

## 브랜드 무드 & 분위기

### 핵심 키워드
- **Sophisticated** (세련된): 과하지 않으면서도 고급스러운
- **Timeless** (시간을 초월한): 유행을 타지 않는 클래식한 아름다움
- **Exclusive** (독점적): 선택받은 느낌, 프리미엄 경험
- **Refined** (정제된): 불필요한 요소를 제거한 순수함
- **Prestigious** (명망 있는): 신뢰감과 권위

### 감성적 목표
고객이 페이지를 볼 때 느껴야 할 감정:
- "이것은 특별하다"
- "나는 가치 있는 선택을 하고 있다"
- "이 브랜드는 나를 이해한다"
- "품질이 보장된다"

### 피해야 할 요소
- ❌ 과도한 장식이나 화려한 그래픽
- ❌ 너무 많은 컬러 사용
- ❌ 빽빽하거나 복잡한 레이아웃
- ❌ 캐주얼하거나 장난스러운 톤
- ❌ 저가형 느낌의 디자인 요소

## 컬러 시스템

### Primary Colors (주요 색상)

**Deep Charcoal** `#2C2C2C`
- 사용처: 주요 제목, 본문 텍스트, 고급스러운 배경
- 느낌: 깊이 있고 강렬하지만 순수 블랙보다 부드러움
- 조합: 골드, 크림과 완벽한 조화

**Champagne Gold** `#D4AF37`
- 사용처: 액센트, CTA 버튼, 아이콘, 구분선
- 느낌: 럭셔리함의 상징, 프리미엄 가치 표현
- 조합: 딥 차콜, 크림 배경에서 빛남

### Secondary Colors (보조 색상)

**Ivory Cream** `#F8F6F0`
- 사용처: 메인 배경, 카드 배경, 섹션 구분
- 느낌: 따뜻하고 부드러운 흰색, 순수 화이트보다 고급스러움
- 조합: 모든 색상의 배경으로 완벽

**Warm Gray** `#8B8680`
- 사용처: 보조 텍스트, 설명문, 아이콘
- 느낌: 중성적이면서 따뜻함
- 조합: 강조하지 않아야 할 정보에 사용

**Deep Burgundy** `#6B2C3E`
- 사용처: 특별한 강조, 프리미엄 섹션 배경, 하이라이트
- 느낌: 부유함, 와인과 같은 성숙함
- 조합: 골드와 함께 사용시 극대화

### Neutral Colors (중립 색상)

**Pure White** `#FFFFFF`
- 사용처: 카드 배경, 입력 필드, 오버레이
- 느낌: 순수함, 명확함

**Soft Border** `#E5E3DB`
- 사용처: 구분선, 카드 테두리, 섹션 경계
- 느낌: 부드럽고 눈에 거슬리지 않음

**Dark Text** `#1A1A1A`
- 사용처: 최고 대비가 필요한 텍스트
- 느낌: 명확한 가독성

### Accent Colors (강조 색상)

**Rose Gold** `#B76E79`
- 사용처: 여성향 제품, 부드러운 강조
- 느낌: 현대적이면서 우아함

**Silver Accent** `#C0C0C0`
- 사용처: 남성향 제품, 기술적 강조
- 느낌: 세련되고 미래지향적

## 컬러 사용 가이드라인

### 컬러 비율 (60-30-10 규칙)
- **60%**: Ivory Cream (배경)
- **30%**: Deep Charcoal (텍스트, 주요 요소)
- **10%**: Champagne Gold (액센트, CTA)

### 접근성 고려
- Deep Charcoal on Ivory Cream: ✅ 대비 비율 11.5:1 (AAA)
- Champagne Gold on Deep Charcoal: ✅ 대비 비율 4.8:1 (AA)
- Warm Gray on Ivory Cream: ✅ 대비 비율 4.2:1 (AA)

## 타이포그래피

### Display Font (디스플레이 폰트)
**Font Family**: Playfair Display (세리프)
- **용도**: 히어로 섹션 제목, 주요 캐치프레이즈
- **크기**: 48-72px (데스크톱), 32-48px (모바일)
- **무게**: Bold (700) 또는 Black (900)
- **줄간격**: 1.1-1.2
- **자간**: -0.02em (약간 타이트하게)
- **색상**: Deep Charcoal 또는 Deep Burgundy
- **특징**: 우아한 세리프체, 클래식하면서 현대적

**예시**:
```
"Experience Unparalleled Luxury"
"프리미엄의 새로운 기준"
```

### Heading Font (제목 폰트)
**Font Family**: Montserrat (산세리프)
- **용도**: 섹션 제목, 카테고리명, 중요 정보
- **크기 H2**: 36-42px (데스크톱), 24-30px (모바일)
- **크기 H3**: 24-30px (데스크톱), 20-24px (모바일)
- **크기 H4**: 18-24px (데스크톱), 16-20px (모바일)
- **무게**: SemiBold (600) 또는 Medium (500)
- **줄간격**: 1.3
- **자간**: 0.01em
- **색상**: Deep Charcoal
- **특징**: 깔끔하고 현대적, 가독성 우수

**예시**:
```
H2: "Crafted to Perfection"
H3: "Premium Materials"
H4: "Design Details"
```

### Body Font (본문 폰트)
**Font Family**: Lora (세리프) 또는 Open Sans (산세리프)
- **용도**: 본문 텍스트, 제품 설명, 상세 정보
- **크기**: 16-18px (데스크톱), 15-16px (모바일)
- **무게**: Regular (400)
- **줄간격**: 1.7-1.8 (가독성 최적화)
- **자간**: 0em (기본)
- **색상**: Deep Charcoal
- **최대 너비**: 65-75자 (최적 가독성)
- **특징**: 편안한 독서 경험

**예시**:
```
"Each piece is meticulously crafted by master artisans
using time-honored techniques passed down through
generations. The result is a timeless work of art
that transcends mere functionality."
```

### Caption Font (캡션 폰트)
**Font Family**: Montserrat (산세리프)
- **용도**: 이미지 캡션, 라벨, 작은 정보
- **크기**: 12-14px
- **무게**: Regular (400) 또는 Medium (500)
- **줄간격**: 1.5
- **자간**: 0.03em (약간 넓게)
- **색상**: Warm Gray
- **특징**: 작지만 명확함

**예시**:
```
"HAND-CRAFTED IN ITALY"
"Limited Edition · Only 100 Pieces"
```

### 타이포그래피 위계

```
Level 1: Display Font (히어로)
   ↓
Level 2: Heading H2 (주요 섹션)
   ↓
Level 3: Heading H3 (서브섹션)
   ↓
Level 4: Heading H4 (작은 제목)
   ↓
Level 5: Body (본문)
   ↓
Level 6: Caption (보조 정보)
```

## 레이아웃 원칙

### 그리드 시스템
**12 Column Grid**
- 컨테이너 최대 너비: 1200px
- 좌우 패딩: 40px (데스크톱), 20px (모바일)
- 컬럼 간격: 24px
- 섹션 간 여백: 120px (데스크톱), 60px (모바일)

### 여백 규칙 (Spacing Scale)

**8px 기반 시스템**:
- XS: 8px - 작은 요소 사이
- S: 16px - 관련 요소 사이
- M: 24px - 컴포넌트 내부
- L: 40px - 컴포넌트 사이
- XL: 64px - 섹션 내부
- XXL: 120px - 섹션 사이

### 섹션 구조

**1. Hero Section (히어로 섹션)**
- 높이: 100vh 또는 700-900px
- 배경: 큰 이미지 (50-60% 오버레이) 또는 Ivory Cream
- 레이아웃: 중앙 정렬 또는 좌측 텍스트 + 우측 이미지
- 요소:
  - Display Font 제목
  - 짧은 부제 (Heading H3)
  - Primary CTA 버튼
  - 스크롤 인디케이터 (선택)

**2. Product/Service Showcase**
- 레이아웃: 번갈아가며 이미지-텍스트 배치
  - 왼쪽 이미지 + 오른쪽 텍스트
  - 오른쪽 이미지 + 왼쪽 텍스트
- 이미지 비율: 1:1 또는 4:3
- 텍스트 영역:
  - 카테고리 라벨 (Caption)
  - 섹션 제목 (H2)
  - 설명 (Body, 2-3단락)
  - CTA 링크 (선택)

**3. Features Grid**
- 레이아웃: 3 컬럼 그리드 (모바일 1 컬럼)
- 각 카드:
  - 아이콘 (64x64px, Champagne Gold)
  - 제목 (H4)
  - 설명 (Body, 2-3줄)
- 카드 스타일:
  - 배경: Pure White
  - 패딩: 40px
  - 라운드: 8px
  - 그림자: subtle (아래 참조)

**4. Testimonials (고객 후기)**
- 레이아웃: 카드 슬라이더 또는 2 컬럼
- 각 후기:
  - 큰 따옴표 (Champagne Gold, 48px)
  - 후기 텍스트 (Body, 이탤릭)
  - 고객명 (Heading H4)
  - 직책/소속 (Caption, Warm Gray)
- 배경: 약간 어두운 섹션 (Deep Charcoal 5% tint)

**5. CTA Section**
- 높이: 400-600px
- 배경: Deep Burgundy 또는 Deep Charcoal
- 레이아웃: 중앙 정렬
- 요소:
  - 강력한 헤드라인 (Display Font, Pure White)
  - 부제 (Body, Ivory Cream)
  - Primary CTA (Champagne Gold 배경)

### 여백 활용 철학
> "Luxury is about space, not fill"

- **넉넉한 여백**: 모든 요소에 충분한 공간
- **시각적 호흡**: 섹션 간 명확한 구분
- **중요도 강조**: 여백으로 시선 유도
- **품질 암시**: 공간 자체가 프리미엄 표현

## UI 요소 스타일

### 버튼

**Primary Button** (주요 행동)
```css
배경: Champagne Gold (#D4AF37)
텍스트: Deep Charcoal (#2C2C2C)
폰트: Montserrat Medium, 16px
패딩: 16px 40px
라운드: 4px
테두리: 없음
호버: 밝기 +10%, 약간 위로 이동 (transform: translateY(-2px))
그림자: 0 4px 12px rgba(212, 175, 55, 0.3)
전환: all 0.3s ease
```

**Secondary Button** (보조 행동)
```css
배경: transparent
텍스트: Champagne Gold (#D4AF37)
폰트: Montserrat Medium, 16px
패딩: 16px 40px
라운드: 4px
테두리: 2px solid #D4AF37
호버: 배경 Champagne Gold, 텍스트 Deep Charcoal
그림자: 없음 → 호버시 0 2px 8px rgba(212, 175, 55, 0.2)
전환: all 0.3s ease
```

**Text Link**
```css
텍스트: Deep Charcoal (#2C2C2C)
폰트: Montserrat SemiBold, 16px
언더라인: 1px solid Champagne Gold (아래 4px 위치)
호버: 텍스트 Champagne Gold
전환: color 0.2s ease
```

### 이미지 처리

- 배경: Pure White 또는 부드러운 그라디언트

- 오버레이: 컨텍스트에 따라 gradient overlay

## 애니메이션 & 인터랙션

### 타이밍
- **빠름**: 0.15s - 작은 변화 (버튼 hover)
- **보통**: 0.3s - 일반 전환 (카드 효과)
- **느림**: 0.5s - 큰 변화 (섹션 등장)

### Easing
- `ease-out`: 요소 등장시
- `ease-in`: 요소 사라질 때
- `ease-in-out`: 상태 변화

### 스크롤 효과
- **Fade In**: 스크롤시 요소 서서히 등장
- **Parallax**: 배경 이미지 느린 스크롤
- **Slide Up**: 요소가 아래에서 위로
