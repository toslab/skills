# Vibrant Energetic Style

밝고 역동적인 에너지가 넘치는 디자인 시스템입니다. 대담한 컬러 조합과 활기찬 비주얼로 젊고 혁신적인 브랜드 이미지를 구축합니다.

## 브랜드 무드 & 분위기

### 핵심 키워드
- **Bold** (대담한): 과감한 선택, 주목받는 디자인
- **Dynamic** (역동적): 움직임과 에너지가 느껴지는
- **Playful** (재미있는): 즐겁고 친근한 분위기
- **Creative** (창의적): 독창적이고 혁신적인
- **Youthful** (젊은): 신선하고 트렌디한

### 감성적 목표
고객이 페이지를 볼 때 느껴야 할 감정:
- "재미있고 흥미롭다"
- "에너지가 느껴진다"
- "독특하고 창의적이다"
- "나와 잘 맞는다"
- "지루하지 않다"

### 피해야 할 요소
- ❌ 어둡고 무거운 색상
- ❌ 지나치게 형식적인 레이아웃
- ❌ 단조로운 타이포그래피
- ❌ 보수적이고 전통적인 디자인
- ❌ 너무 많은 여백 (활기를 죽임)

### Gradient Combinations (그라디언트 조합)

**Sunset Gradient**
```css
background: linear-gradient(135deg, #FF6B6B 0%, #FFD60A 100%);
```
- 용도: 히어로 배경, 카드 배경
- 느낌: 따뜻함, 에너지

**Electric Gradient**
```css
background: linear-gradient(135deg, #6B4FEE 0%, #FF3D88 100%);
```
- 용도: CTA 버튼, 특별 섹션
- 느낌: 역동적, 현대적

**Fresh Gradient**
```css
background: linear-gradient(135deg, #7DFF6B 0%, #00D9FF 100%);
```
- 용도: 새로운 기능, 하이라이트
- 느낌: 신선함, 혁신

**Rainbow Gradient** (조심스럽게 사용)
```css
background: linear-gradient(
  90deg,
  #FF3D88 0%,
  #FFD60A 25%,
  #7DFF6B 50%,
  #00D9FF 75%,
  #6B4FEE 100%
);
```
- 용도: 구분선, 장식 요소
- 느낌: 다채로움, 포용

## 컬러 사용 가이드라인

### 컬러 비율
- **60%**: White/Cream (배경, 여백)
- **25%**: Primary/Secondary Colors (그래픽, 강조)
- **15%**: Charcoal (텍스트, 구조)

### 대담한 조합 규칙
1. **보색 대비**: Purple + Yellow, Pink + Green
2. **삼색 조화**: Purple + Pink + Yellow
3. **그라디언트**: 두 가지 인접 색상
4. **포인트 컬러**: 섹션마다 다른 메인 컬러 OK

### 접근성 주의
- Purple on White: ✅ 4.6:1 (AA)
- Yellow on White: ❌ 1.2:1 → 텍스트 사용 금지
- Pink on White: ✅ 4.1:1 (AA, small text)
- Charcoal on White: ✅ 14.1:1 (AAA)

## 타이포그래피

### Display Font (디스플레이 폰트)
**Font Family**: Poppins Black 또는 Outfit ExtraBold
- **용도**: 히어로 헤드라인, 임팩트 있는 제목
- **크기**: 64-96px (데스크톱), 36-48px (모바일)
- **무게**: ExtraBold (800) 또는 Black (900)
- **줄간격**: 1.0-1.1 (타이트)
- **자간**: -0.02em
- **색상**: Deep Charcoal, 또는 그라디언트 텍스트
- **특징**: 강렬하고 눈에 띄는

**그라디언트 텍스트 예시**:
```css
background: linear-gradient(135deg, #6B4FEE 0%, #FF3D88 100%);
-webkit-background-clip: text;
-webkit-text-fill-color: transparent;
```

**예시**:
```
"UNLEASH YOUR CREATIVITY"
"한계를 넘어라"
```

### Heading Font (제목 폰트)
**Font Family**: Poppins (산세리프)
- **용도**: 섹션 제목, 카테고리명
- **크기 H2**: 40-52px (데스크톱), 28-36px (모바일)
- **크기 H3**: 28-36px (데스크톱), 22-28px (모바일)
- **크기 H4**: 20-24px (데스크톱), 18-20px (모바일)
- **무게**: Bold (700) 또는 SemiBold (600)
- **줄간격**: 1.2
- **자간**: -0.01em
- **색상**: Deep Charcoal 또는 Primary Colors
- **특징**: 둥글고 친근함

**예시**:
```

H3: "Our Features"
```

### Body Font (본문 폰트)
**Font Family**: Inter 또는 DM Sans
- **용도**: 본문, 설명, 리스트
- **크기**: 16-18px (데스크톱), 16px (모바일)
- **무게**: Regular (400), Medium (500) 강조시
- **줄간격**: 1.6-1.7
- **자간**: 0em

- **무게**: Bold (700)

- **특징**: 독특하고 개성 있음

## 레이아웃 원칙

### 자유로운 그리드
- 전통적 12컬럼보다 **비대칭 레이아웃** 선호
- 요소들이 겹치는 것 허용 (z-index 활용)
- 사선 배치, 회전 가능 (subtle, 5-15도)

### 여백 규칙

**8px 기반 + 유연성**:
```
XS:    8px
S:     16px
M:     24px
L:     40px
XL:    56px
XXL:   80px
```

### 섹션 구조

**1. Hero Section**
- 높이: 100vh
- 배경:
  - 옵션 1: 밝은 그라디언트 (Sunset/Electric)
  - 옵션 2: 대담한 단색 + 그래픽 패턴
  - 옵션 3: 애니메이션 배경
- 레이아웃: 비대칭 (60/40 또는 자유 배치)
- 요소:
  - 큰 Display 제목 (그라디언트 텍스트 가능)
  - 짧은 서브타이틀
  - 눈에 띄는 CTA (그라디언트 버튼)
  - 역동적인 그래픽/일러스트레이션
- 특징: 즉시 시선을 사로잡음

**2. Feature Showcase**
- 레이아웃: 카드 그리드 또는 Bento Grid
- 카드:
  - 각기 다른 Primary Color 배경
  - 아이콘 (큼직한, 64-96px)
  - 제목 + 짧은 설명
  - 호버시 살짝 확대 (scale: 1.05)
- 간격: 16-24px (빽빽한 느낌 OK)

**3. Visual Content Blocks**
- 레이아웃: 이미지와 텍스트가 역동적으로 교차
- 이미지:
  - 둥근 모서리 (16-24px)
  - 컬러 틴트 오버레이 (Primary Colors 15% opacity)
  - 사선 배치 또는 겹침 OK
- 그래픽 요소:
  - 큰 점, 선, 추상 도형
  - Primary Colors로 강조

**4. Stats/Numbers**
- 레이아웃: 3-4개, 자유 배치
- 각 통계:
  - 거대한 숫자 (Accent Font, 72-120px, 컬러풀)
  - 라벨 (작게, 대문자)
  - 배경: 컬러 블록 또는 그라디언트
- 애니메이션: 카운트 업 효과

**5. Testimonials**
- 레이아웃: 카드 형식, 각기 다른 컬러
- 각 카드:
  - 배경: Primary/Secondary Color (밝게)
  - 큰 따옴표 (대조 컬러)
  - 후기 (본문)
  - 프로필 이미지 (둥글게)
  - 이름 + 직함

**6. CTA Section**
- 배경: 강렬한 그라디언트
- 레이아웃: 중앙 정렬
- 요소:
  - 큰 헤드라인 (White)
  - 대비되는 CTA 버튼
- 추가: 애니메이션 요소 (떠다니는 도형 등)

### 역동성 원칙

1. **비대칭**: 좌우 대칭 피하기
2. **겹침**: 요소들이 살짝 겹치게
3. **각도**: 미세한 회전 (3-10도)
4. **스케일 대비**: 큰 것은 매우 크게, 작은 것은 작게
5. **컬러 블록**: 배경에 큰 컬러 도형

## 애니메이션 & 인터랙션

### 원칙
- **활기차게**: 재미있고 눈에 띄게
- **과하지 않게**: 사용성 해치지 않는 선
- **의외성**: 예상치 못한 즐거움

### 허용되는 애니메이션
- **Bounce**: 버튼, 아이콘
- **Wiggle**: 호버시 살짝 흔들림
- **Pulse**: 중요 요소 맥동
- **Slide & Fade**: 요소 등장
- **Rotate**: 아이콘 회전
- **Scale**: 확대/축소
- **Gradient Shift**: 그라디언트 이동

### 타이밍
- **Quick**: 0.3s
- **Standard**: 0.4s
- **Playful**: 0.5s (with bounce easing)

### Easing
- `cubic-bezier(0.34, 1.56, 0.64, 1)` - Bounce
- `cubic-bezier(0.68, -0.55, 0.265, 1.55)` - Back

### 마이크로 인터랙션
```css
/* Hover Bounce */
.btn:hover {
  animation: bounce 0.5s;
}

@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-8px); }
}

/* Gradient Animation */
.gradient-bg {
  background-size: 200% 200%;
  animation: gradient-shift 3s ease infinite;
}

@keyframes gradient-shift {
  0% { background-position: 0% 50%; }
  50% { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}
```
