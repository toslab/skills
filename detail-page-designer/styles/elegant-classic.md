# Elegant Classic Style

시대를 초월하는 우아함과 클래식한 아름다움의 디자인 시스템입니다. 전통적 가치와 현대적 감각을 조화롭게 결합하여 신뢰감과 품격을 전달합니다.

## 브랜드 무드 & 분위기

### 핵심 키워드
- **Timeless** (시간을 초월한): 유행을 타지 않는 보편적 아름다움
- **Elegant** (우아한): 세련되고 품위 있는
- **Trustworthy** (신뢰할 수 있는): 안정감과 믿음을 주는
- **Sophisticated** (정교한): 세밀하고 고급스러운
- **Heritage** (전통의): 역사와 전통을 존중하는

### 감성적 목표
고객이 페이지를 볼 때 느껴야 할 감정:
- "신뢰할 수 있다"
- "품격이 있다"
- "오래도록 가치 있다"
- "전문적이다"
- "안정적이다"

### 피해야 할 요소
- ❌ 너무 화려하거나 현란한 컬러
- ❌ 트렌디한 폰트 (빠르게 구식됨)
- ❌ 과도한 애니메이션
- ❌ 비대칭적이고 혼란스러운 레이아웃
- ❌ 캐주얼하거나 가벼운 톤

## 컬러 시스템

## 컬러 사용 가이드라인

### 컬러 비율 (60-30-10 규칙)
- **60%**: Cream/Beige (배경)
- **30%**: Navy/Forest Green (구조, 텍스트)
- **10%**: Gold/Burgundy (액센트)

### 클래식 페어링
- Navy + Gold + Cream
- Forest Green + Terracotta + Beige
- Burgundy + Gold + White

### 접근성
- Navy on Cream: ✅ 8.4:1 (AAA)
- Forest Green on Cream: ✅ 7.2:1 (AAA)
- Gold on Navy: ✅ 4.5:1 (AA)
- Charcoal on Cream: ✅ 10.1:1 (AAA)

## 타이포그래피

### Display Font (디스플레이 폰트)
**Font Family**: Cormorant Garamond 또는 Playfair Display (세리프)
- **용도**: 히어로 타이틀, 주요 헤드라인
- **크기**: 52-72px (데스크톱), 36-48px (모바일)
- **무게**: SemiBold (600) 또는 Bold (700)
- **줄간격**: 1.2
- **자간**: -0.01em
- **색상**: Navy Blue, Deep Charcoal
- **특징**: 우아한 세리프, 시대를 초월한 아름다움

**예시**:
```
"Timeless Excellence"
"전통의 가치"
```

### Heading Font (제목 폰트)
**Font Family**: Libre Baskerville 또는 Crimson Pro (세리프)
- **용도**: 섹션 제목, 중요 제목
- **크기 H2**: 36-44px (데스크톱), 28-32px (모바일)
- **크기 H3**: 28-32px (데스크톱), 22-26px (모바일)
- **크기 H4**: 20-24px (데스크톱), 18-20px (모바일)
- **무게**: Bold (700) 또는 SemiBold (600)
- **줄간격**: 1.3
- **자간**: 0em
- **색상**: Navy Blue, Forest Green
- **특징**: 읽기 쉬운 클래식 세리프

**예시**:
```
H2: "Our Heritage"
H3: "Craftsmanship"
```

### Body Font (본문 폰트)
**Font Family**: Lora (세리프) 또는 Merriweather (세리프)
- **용도**: 본문 텍스트, 설명
- **크기**: 17-19px (데스크톱), 16-18px (모바일)
- **무게**: Regular (400)
- **줄간격**: 1.7-1.8 (편안한 읽기)
- **자간**: 0.01em
- **색상**: Charcoal (#3D3935)
- **최대 너비**: 70자
- **특징**: 세리프로 전통적이지만 스크린에서도 읽기 좋음

**대안 (산세리프)**:
- **Font Family**: Source Sans Pro 또는 Open Sans
- 더 현대적인 느낌을 원할 때 본문에 사용

**예시**:
```
"Our company has been dedicated to excellence for over
three generations. We believe in the enduring value of
quality craftsmanship and timeless design principles
that stand the test of time."
```

### Small Text (작은 텍스트)
**Font Family**: Source Sans Pro (산세리프)
- **용도**: 라벨, 날짜, 메타데이터
- **크기**: 13-15px
- **무게**: Regular (400) 또는 SemiBold (600)
- **줄간격**: 1.5
- **자간**: 0.05em (약간 넓게)
- **색상**: Soft Gray (#A8A49B)
- **대문자**: 레이블에 자주 사용

**예시**:
```
"ESTABLISHED 1895"
"Updated March 2024"
```

### 타이포그래피 원칙

1. **세리프 우선**: 제목과 본문 모두 세리프 사용 가능
2. **산세리프는 보조**: 라벨, 캡션, UI 요소
3. **크기 차이 명확**: 위계 구조가 한눈에
4. **여백 넉넉히**: 텍스트에 충분한 호흡
5. **정렬 신중히**: 중앙 정렬은 제목만, 본문은 좌측

**1. Hero Section**
- 높이: 80vh 또는 700px
- 배경:
  - 옵션 1: 고급스러운 사진 (50% 어두운 오버레이)
  - 옵션 2: Cream 배경에 큰 타이포그래피
  - 옵션 3: 미묘한 패턴 (damask, 격자 등)
- 레이아웃: 중앙 정렬
- 요소:
  - Display Font 제목 (중앙)
  - 짧은 서브타이틀 (세리프)
  - Primary CTA (우아한 버튼)
  - 스크롤 인디케이터
- 특징: 위엄 있고 첫인상이 강함

**2. Introduction Section**
- 레이아웃: 중앙 정렬, 단일 컬럼
- 요소:
  - 인트로 텍스트 (큰 본문, 18-20px)
  - 최대 너비: 800px
  - 넉넉한 줄간격
- 배경: Cream 또는 White

**3. Feature Grid**
- 레이아웃: 3 컬럼 그리드, 대칭
- 각 아이템:
  - 아이콘 (선형, Gold 또는 Navy)
  - 제목 (H4, 세리프)
  - 설명 (본문)
- 정렬: 중앙 또는 좌측
- 배경: Warm Beige 섹션

**4. Content Showcase**
- 레이아웃: 2 컬럼, 50/50
- 좌측 이미지 + 우측 텍스트 (대칭 반복)
- 이미지:
  - 고품질, 전문적
  - 미묘한 프레임 효과 (Gold 얇은 테두리)
- 텍스트:
  - 제목 (H2, 세리프)
  - 본문 (세리프)
  - 선택적 CTA

**5. Testimonials**
- 레이아웃: 단일 컬럼, 중앙 정렬
- 각 후기:
  - 큰 따옴표 (Antique Gold, 세리프)
  - 후기 텍스트 (이탤릭, 큰 본문 20px)
  - 구분선 (Gold, 1px)
  - 고객명 (소문자, 작게)
  - 직함/회사 (Small Text)
- 배경: White 카드

**6. Timeline / History**
- 레이아웃: 수직 타임라인
- 좌측: 연도 (큰 숫자, 세리프)
- 우측: 설명
- 연결선: Gold 또는 Navy
- 배경: Cream

**7. CTA Section**
- 배경: Navy Blue 또는 Forest Green
- 레이아웃: 중앙 정렬
- 요소:
  - 제목 (H2, 세리프, Cream)
  - 서브텍스트 (본문, White)
  - Primary CTA (Gold 배경 또는 outlined White)
- 패딩: 넉넉하게

## 애니메이션 & 인터랙션

### 원칙
- **절제되게**: 과하지 않음
- **우아하게**: 부드럽고 자연스럽게
- **의미 있게**: 사용자 경험 향상 목적

### 타이밍
- **Slow**: 0.4-0.5s - 대부분의 전환
- **Medium**: 0.3s - 버튼 호버
- **Fast**: 0.2s - 작은 변화

### Easing
- `ease-in-out` - 부드러운 시작과 끝
- `ease-out` - 요소 등장시

### 허용되는 애니메이션
- **Fade**: 부드러운 등장/사라짐
- **Slide**: 느리게 위로 (20-30px)
- **Color Transition**: 배경, 테두리 색상
- **Subtle Scale**: 미세 확대 (1.0 → 1.02)

### 피해야 할 것
- ❌ Bounce, wiggle (너무 캐주얼)
- ❌ 빠른 애니메이션
- ❌ 복잡한 keyframes
- ❌ 화려한 효과

### 예시
```css
/* Elegant Fade In */
.fade-in {
  opacity: 0;
  animation: fadeInUp 0.8s ease-out forwards;
}

@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(30px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* Hover Effect */
.card:hover {
  transform: translateY(-4px);
  transition: transform 0.4s ease-out;
}
```

- **여백**: 75-80%로 감소
- **그리드**: 1 컬럼
- **이미지**: Full width
- **버튼**: Full width 또는 centered

### 우아함 유지
- 모바일에서도 넉넉한 여백
- 텍스트 읽기 편하게
- 터치 타겟 충분히 크게 (44x44px)
