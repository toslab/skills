# Modern Minimal Style

깨끗하고 현대적인 미니멀리즘 디자인 시스템입니다. 불필요한 요소를 제거하고 본질에 집중하여 명확하고 효율적인 사용자 경험을 제공합니다.

## 브랜드 무드 & 분위기

### 핵심 키워드
- **Clean** (깨끗한): 시각적 잡음이 없는 정돈된 공간
- **Efficient** (효율적): 빠른 정보 전달과 명확한 구조
- **Contemporary** (현대적): 최신 디자인 트렌드 반영
- **Focused** (집중된): 핵심 메시지에 집중
- **Professional** (전문적): 신뢰감 있고 체계적

### 감성적 목표
고객이 페이지를 볼 때 느껴야 할 감정:
- "직관적이고 이해하기 쉽다"
- "현대적이고 혁신적이다"
- "신뢰할 수 있다"
- "시간을 낭비하지 않는다"
- "전문적이다"

### 피해야 할 요소
- ❌ 과도한 장식이나 그라디언트
- ❌ 너무 많은 컬러 사용
- ❌ 복잡한 패턴
- ❌ 불필요한 애니메이션
- ❌ 작고 읽기 힘든 텍스트

## 컬러 시스템

### Primary Colors (주요 색상)

**Pure Black** `#000000`
- 사용처: 주요 제목, 강조 텍스트, 아이콘
- 느낌: 강력함, 명확함, 현대적
- 조합: 화이트, 그레이 배경에서 최고 대비

**Electric Blue** `#0066FF`
- 사용처: CTA 버튼, 링크, 중요한 인터랙티브 요소
- 느낌: 에너지, 신뢰, 기술적
- 조합: 화이트/블랙과 강렬한 대비

### Secondary Colors (보조 색상)

**Pure White** `#FFFFFF`
- 사용처: 메인 배경, 카드 배경
- 느낌: 순수함, 여백, 깨끗함
- 조합: 모든 색상의 기본 배경

**Light Gray** `#F5F5F5`
- 사용처: 섹션 구분 배경, subtle 강조
- 느낌: 부드러운 구분
- 조합: 화이트와 미묘한 대비

**Medium Gray** `#999999`
- 사용처: 보조 텍스트, 비활성 요소
- 느낌: 중립적, 차분함
- 조합: 중요하지 않은 정보

**Dark Gray** `#333333`
- 사용처: 본문 텍스트, 일반 아이콘
- 느낌: 블랙보다 부드럽지만 여전히 명확
- 조합: 장시간 읽기에 적합

### Accent Colors (강조 색상)

**Success Green** `#00C853`
- 사용처: 성공 메시지, 긍정적 피드백
- 느낌: 신선함, 성공

**Warning Orange** `#FF9100`
- 사용처: 주의 메시지, 중요 알림
- 느낌: 주의환기, 에너지

**Error Red** `#FF5252`
- 사용처: 오류 메시지, 필수 항목
- 느낌: 긴급함, 주의

### Neutral Colors (중립 색상)

**Border Gray** `#E0E0E0`
- 사용처: 구분선, 카드 테두리
- 느낌: 미묘한 구분

**Hover Gray** `#F0F0F0`
- 사용처: 버튼/카드 호버 배경
- 느낌: 인터랙티브 피드백

## 컬러 사용 가이드라인

### 컬러 비율
- **70%**: White/Light Gray (배경)
- **20%**: Black/Dark Gray (텍스트, 주요 요소)
- **10%**: Electric Blue (액센트, CTA)

### 접근성 고려
- Pure Black on White: ✅ 대비 비율 21:1 (AAA)
- Dark Gray on White: ✅ 대비 비율 12.6:1 (AAA)
- Electric Blue on White: ✅ 대비 비율 4.7:1 (AA)
- Medium Gray on White: ✅ 대비 비율 4.6:1 (AA)

## 타이포그래피

### Display Font (디스플레이 폰트)
**Font Family**: Inter Black 또는 SF Pro Display Bold
- **용도**: 히어로 섹션 메인 헤드라인
- **크기**: 56-80px (데스크톱), 32-48px (모바일)
- **무게**: Black (900) 또는 Bold (700)
- **줄간격**: 1.1
- **자간**: -0.03em (타이트하게)
- **색상**: Pure Black
- **특징**: 강력하고 임팩트 있는

**예시**:
```
"Design Simplified"
"혁신의 시작"
```

### Heading Font (제목 폰트)
**Font Family**: Inter (산세리프)
- **용도**: 모든 레벨의 제목
- **크기 H1**: 48px (데스크톱), 32px (모바일)
- **크기 H2**: 36px (데스크톱), 28px (모바일)
- **크기 H3**: 24px (데스크톱), 20px (모바일)
- **크기 H4**: 20px (데스크톱), 18px (모바일)
- **무게**: SemiBold (600) 또는 Bold (700)
- **줄간격**: 1.2-1.3
- **자간**: -0.01em
- **색상**: Pure Black 또는 Dark Gray
- **특징**: 깔끔하고 현대적

**예시**:
```
H1: "Our Platform"
H2: "Key Features"
H3: "How It Works"
```

### Body Font (본문 폰트)
**Font Family**: Inter (산세리프)
- **용도**: 본문 텍스트, 설명, 리스트
- **크기**: 16px (기본), 18px (편안한 읽기)
- **무게**: Regular (400)
- **줄간격**: 1.6-1.7
- **자간**: 0em
- **색상**: Dark Gray (#333333)
- **최대 너비**: 70자
- **특징**: 가독성 우수, 스크린에 최적화

**예시**:
```
"Our platform streamlines your workflow with
intelligent automation and intuitive design.
Start achieving more with less effort."
```

### Small Text (작은 텍스트)
**Font Family**: Inter (산세리프)
- **용도**: 라벨, 메타데이터, 캡션
- **크기**: 14px (일반), 12px (최소)
- **무게**: Medium (500) 또는 Regular (400)
- **줄간격**: 1.5
- **자간**: 0.02em
- **색상**: Medium Gray (#999999)
- **특징**: 명확하지만 부담스럽지 않음

**예시**:
```
"Last updated: March 2024"
"CATEGORY"
```

### 타이포그래피 규칙

1. **하나의 폰트 패밀리 사용**: Inter (또는 SF Pro, Helvetica Neue)
2. **무게로 위계 표현**: Black/Bold/SemiBold/Medium/Regular
3. **크기 점프 명확하게**: 최소 4px 차이
4. **올블랙 대신 다크 그레이**: 본문은 #333333

## 레이아웃 원칙

### 그리드 시스템
**12 Column Grid** (유연한 레이아웃)
- 컨테이너 최대 너비: 1140px (콘텐츠), 1440px (full-width)
- 좌우 패딩: 24px (데스크톱), 16px (모바일)
- 컬럼 간격: 24px
- 섹션 간 여백: 80px (데스크톱), 48px (모바일)

### 여백 규칙 (Spacing Scale)

**4px 기반 시스템** (정밀한 조정):
```
XXS:   4px   - 아주 작은 간격
XS:    8px   - 인라인 요소
S:     16px  - 관련 요소
M:     24px  - 컴포넌트 내부
L:     32px  - 컴포넌트 사이
XL:    48px  - 섹션 내부
XXL:   64px  - 섹션 사이
XXXL:  96px  - 메이저 섹션
```

### 섹션 구조

**1. Hero Section (히어로 섹션)**
- 높이: 100vh (최대 900px)
- 배경: Pure White
- 레이아웃: 중앙 정렬 또는 좌측 텍스트 블록
- 요소:
  - Display Font 메인 헤드라인
  - Body 서브타이틀 (1-2줄)
  - Primary CTA 버튼
  - Hero 이미지/일러스트레이션 (선택)
- 특징: 극도로 깨끗하고 집중된

**2. Feature Grid (기능 그리드)**
- 레이아웃: 3 또는 4 컬럼 그리드
- 간격: 24px
- 각 아이템:
  - 아이콘 (선택, 32x32px)
  - 제목 (H3 또는 H4)
  - 짧은 설명 (2-3줄)
- 배경: White (카드 없이) 또는 Light Gray
- 정렬: 좌측 또는 중앙

**3. Content Blocks (콘텐츠 블록)**
- 레이아웃:
  - 2 컬럼 (50/50 또는 60/40)
  - 이미지 + 텍스트 번갈아
- 이미지:
  - 고품질, 미니멀한 배경
  - 라운드 코너 (8px) 또는 sharp edges
- 텍스트:
  - 제목 (H2)
  - 본문 (Body)
  - CTA 링크 또는 버튼

**4. Stats Section (통계 섹션)**
- 레이아웃: 3-4 컬럼, 중앙 정렬
- 각 통계:
  - 큰 숫자 (Display Font, 48-64px)
  - 라벨 (Small Text, Medium Gray)
- 배경: Light Gray 또는 White
- 간격: 넉넉하게

**5. CTA Section (행동유도 섹션)**
- 높이: 400-600px
- 배경: Pure Black 또는 Electric Blue
- 레이아웃: 중앙 정렬
- 요소:
  - 헤드라인 (H1, White)
  - 서브텍스트 (Body, Light Gray)
  - Primary CTA (White 배경)

### 미니멀리즘 원칙

1. **여백이 디자인**: 비어있는 공간도 요소
2. **정렬 엄격히**: 모든 것을 그리드에 맞춤
3. **대비로 강조**: 컬러 대신 크기와 무게
4. **삭제의 예술**: 필요 없으면 제거
5. **수평/수직 정렬**: 시각적 안정감

## 애니메이션 & 인터랙션

### 원칙
- **최소한으로**: 꼭 필요한 곳에만
- **빠르게**: 0.2-0.3s (느리면 답답함)
- **의미 있게**: 피드백 제공 목적

### 타이밍
- **Instant**: 0.1s - 색상 변화
- **Quick**: 0.2s - 버튼 호버, 작은 이동
- **Standard**: 0.3s - 카드 효과, 페이드

### Easing
- `cubic-bezier(0.4, 0, 0.2, 1)` - Material Design standard

### 허용되는 애니메이션
- **Fade**: 요소 등장/사라짐
- **Slide**: 아래→위 (subtle, 4-8px)
- **Color Transition**: 배경, 테두리 색상 변화
- **Scale**: 미세 확대 (1.0 → 1.02)

### 피해야 할 애니메이션
- ❌ Bounce
- ❌ Rotate (아이콘 제외)
- ❌ Complex keyframes
- ❌ Parallax (과도한)
