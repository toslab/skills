# Detail Page Designer Skill

상세페이지를 위한 전문적이고 일관성 있는 디자인 시스템을 제공하는 skill입니다. 각 디자인 스타일은 신중하게 선택된 컬러 팔레트, 폰트 페어링, 레이아웃 원칙, 그리고 독특한 무드와 분위기를 포함합니다.

## 목적

제품, 서비스, 포트폴리오 등의 상세페이지를 디자인할 때:
- 일관된 브랜드 아이덴티티 구축
- 전문적인 타이포그래피 적용
- 감성적으로 공감되는 컬러 시스템 사용
- 명확한 시각적 위계 구조 수립
- 사용자 경험을 고려한 레이아웃 구성

## 사용 방법

### 기본 워크플로우

1. **사용자 요구사항 파악**: 어떤 유형의 상세페이지인지, 목표 고객층, 원하는 분위기 확인
2. **스타일 제시**: 5가지 미리 정의된 스타일 중 가장 적합한 것을 추천하거나, 모든 옵션 제시
3. **스타일 선택 대기**: 사용자가 명확히 선택할 때까지 기다림
4. **디자인 적용**: 선택된 스타일의 모든 요소(컬러, 폰트, 레이아웃, 무드)를 일관되게 적용

### 사용 예시

```
사용자: "프리미엄 가구 제품의 상세페이지를 만들어줘"
Assistant:
1. styles/luxury-premium.md 파일을 읽어서 제안
2. 또는 여러 스타일을 보여주고 선택 요청
3. 선택 후 해당 스타일의 모든 디자인 요소를 적용
```

## 제공되는 디자인 스타일

총 5가지의 완성도 높은 디자인 스타일을 제공합니다:

### 1. **Luxury Premium** (럭셔리 프리미엄)
- 고급스럽고 세련된 분위기
- 최상급 제품/서비스에 적합
- 절제된 컬러와 우아한 타이포그래피

### 2. **Modern Minimal** (모던 미니멀)
- 깔끔하고 현대적인 디자인
- 테크, SaaS, 스타트업에 최적
- 여백을 활용한 시각적 정리

### 3. **Vibrant Energetic** (활기찬 에너제틱)
- 밝고 역동적인 느낌
- 젊은 타겟층, 크리에이티브 제품
- 대담한 컬러 조합

### 4. **Elegant Classic** (우아한 클래식)
- 시간이 지나도 변하지 않는 아름다움
- 전통적이면서도 세련됨
- 신뢰감과 안정감 제공

### 5. **Warm Natural** (따뜻한 내츄럴)
- 친근하고 편안한 분위기
- 오가닉, 웰니스, 라이프스타일 제품
- 자연스러운 컬러와 질감

## 디자인 스타일 구조

각 스타일 파일(`styles/` 디렉토리)은 다음을 포함합니다:

### 컬러 시스템
- **Primary Colors**: 브랜드를 대표하는 주요 색상 (2-3개)
- **Secondary Colors**: 보조 색상 및 강조 색상
- **Neutral Colors**: 배경, 텍스트, 구분선 등에 사용
- **Accent Colors**: CTA 버튼, 중요 요소 강조용
- 모든 컬러는 HEX 코드와 사용 용도 명시

### 타이포그래피
- **Display Font**: 큰 제목, 히어로 섹션용 (24pt 이상)
- **Heading Font**: 섹션 제목, 부제목용 (18-24pt)
- **Body Font**: 본문 텍스트용 (14-16pt)
- **Caption Font**: 작은 설명, 라벨용 (12pt 이하)
- 폰트 크기, 줄간격, 자간 가이드라인 포함

### 레이아웃 원칙
- 그리드 시스템 (12컬럼 또는 적합한 구조)
- 여백(margin/padding) 규칙
- 섹션 구분 방법
- 이미지와 텍스트 비율

### 무드 & 스타일
- 전반적인 분위기 설명
- 추구하는 감성
- 피해야 할 요소
- 참고할 만한 디자인 방향성

### UI 요소 스타일
- 버튼 디자인 (Primary, Secondary, Tertiary)
- 카드 컴포넌트 스타일
- 아이콘 스타일 (선형/채움, 크기)
- 이미지 처리 방법 (라운드 코너, 그림자 등)

## 커스텀 디자인 시스템 생성

미리 정의된 5가지 스타일이 적합하지 않을 경우:

1. **요구사항 수집**:
   - 브랜드 아이덴티티
   - 타겟 오디언스
   - 경쟁사 분석
   - 선호하는 컬러/폰트/스타일

2. **커스텀 시스템 생성**:
   - 위 "디자인 스타일 구조"와 동일한 형식으로 새로운 스타일 정의
   - 브랜드에 최적화된 컬러 팔레트 개발
   - 적절한 폰트 페어링 선택
   - 일관된 레이아웃 규칙 수립

3. **검토 및 승인**:
   - 생성된 커스텀 디자인 시스템을 사용자에게 제시
   - 피드백 반영 및 수정
   - 최종 승인 후 적용

## 적용 시 주의사항

### ✅ 해야 할 것
- 선택된 스타일의 모든 요소를 일관되게 적용
- 컬러 대비 비율 확인 (접근성 WCAG AA 이상)
- 타이포그래피 위계 구조 명확히 유지
- 모바일 반응형 고려
- 브랜드 가이드라인 준수

### ❌ 하지 말아야 할 것
- 한 페이지에 여러 스타일 혼용
- 가독성을 해치는 컬러 조합
- 일관성 없는 여백 사용
- 과도한 장식 요소
- 스타일 가이드 무시

## 실전 적용 프로세스

### Step 1: 컬러 시스템 적용
```
- 배경색: Neutral - Background
- 주요 제목: Primary Color + Display Font
- 본문: Neutral - Text + Body Font
- CTA 버튼: Accent Color + 적절한 라운딩
- 구분선/카드: Neutral - Border
```

### Step 2: 타이포그래피 적용
```
- H1 (페이지 제목): Display Font, 48-64px, Bold
- H2 (섹션 제목): Heading Font, 32-40px, Semi-Bold
- H3 (서브섹션): Heading Font, 24-28px, Medium
- Body: Body Font, 16-18px, Regular, line-height 1.6
- Caption: Caption Font, 12-14px, Regular
```

### Step 3: 레이아웃 구성
```
- 히어로 섹션: 큰 이미지/비주얼 + 짧은 캐치프레이즈
- 제품/서비스 설명: 이미지와 텍스트 번갈아 배치
- 특징/장점: 아이콘 그리드 또는 카드 레이아웃
- CTA 섹션: 명확한 행동 유도
- 푸터: 보조 정보 및 링크
```

### Step 4: 세부 요소 스타일링
```
- 버튼: 선택된 스타일의 버튼 디자인 가이드 따르기
- 카드: 그림자, 라운딩, 패딩 일관성 유지
- 이미지: 동일한 라운드 코너, 필터 효과 적용
- 아이콘: 통일된 스타일, 적절한 크기
```

## 파일 구조 및 리소스

```
styles/
├── luxury-premium.md        # 럭셔리 프리미엄 스타일
├── modern-minimal.md        # 모던 미니멀 스타일
├── vibrant-energetic.md     # 활기찬 에너제틱 스타일
├── elegant-classic.md       # 우아한 클래식 스타일
└── warm-natural.md          # 따뜻한 내츄럴 스타일
```

각 파일은 완전하고 즉시 사용 가능한 디자인 시스템을 포함합니다.

## 기술적 고려사항

### 웹 구현시
- CSS 변수로 컬러 시스템 정의
- 웹 폰트 로딩 최적화
- 반응형 타이포그래피 스케일
- 컴포넌트 기반 디자인 시스템

### 디자인 툴 사용시
- Figma/Sketch: 컬러 스타일, 텍스트 스타일 사전 정의
- 컴포넌트 라이브러리 구축
- 재사용 가능한 레이아웃 템플릿

## 예시 사용 시나리오

### 시나리오 1: 전자제품 상세페이지
```
1. 제품 특성 파악: 고급 노이즈 캔슬링 헤드폰
2. 추천 스타일: Modern Minimal 또는 Luxury Premium
3. 사용자 선택: Luxury Premium
4. 적용:
   - 컬러: 딥 블랙, 골드 액센트, 크림 배경
   - 폰트: 세리프 디스플레이 + 산세리프 본문
   - 레이아웃: 큰 제품 이미지, 우아한 여백
   - 무드: 프리미엄, 세련됨, 정숙함
```

### 시나리오 2: 헬스케어 앱 소개 페이지
```
1. 제품 특성 파악: 명상 및 웰니스 앱
2. 추천 스타일: Warm Natural
3. 사용자 선택: Warm Natural
4. 적용:
   - 컬러: 소프트 그린, 베이지, 따뜻한 오렌지
   - 폰트: 부드러운 산세리프
   - 레이아웃: 유기적 형태, 자연스러운 흐름
   - 무드: 편안함, 치유, 자연
```

## 성공적인 상세페이지를 위한 체크리스트

- [ ] 명확한 시각적 위계 구조
- [ ] 일관된 컬러 시스템 적용
- [ ] 가독성 높은 타이포그래피
- [ ] 적절한 여백과 공간 활용
- [ ] 브랜드 아이덴티티 반영
- [ ] 모바일 최적화
- [ ] 빠른 로딩 속도
- [ ] 명확한 CTA(Call-to-Action)
- [ ] 접근성 고려
- [ ] 일관된 무드와 톤
