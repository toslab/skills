# toslab 브랜드 스토리

## 브랜드 개요

**toslab**은 혁신적인 기술로 일상을 더 나은 방향으로 변화시키는 것을 목표로 합니다.

## 우리의 가치

### 혁신 (Innovation)
끊임없이 새로운 것을 시도하고, 기존의 방식에 도전합니다.

### 신뢰 (Trust)
고객과의 약속을 지키며, 투명하고 정직한 관계를 유지합니다.

### 탁월함 (Excellence)
최고 수준의 품질과 서비스를 제공하기 위해 노력합니다.

### 협력 (Collaboration)
함께 성장하고, 더 큰 가치를 만들어갑니다.

## 브랜드 보이스

### 톤 (Tone)
- **전문적이지만 친근한**: 기술적 전문성을 유지하면서도 접근하기 쉬운 언어 사용
- **혁신적이지만 신뢰할 수 있는**: 새로운 아이디어를 제시하되, 검증된 방법론 활용
- **자신감 있지만 겸손한**: 우리의 강점을 분명히 하되, 지나치게 자랑하지 않음

### 사용 언어
- ✅ 사용: 혁신, 솔루션, 파트너, 성장, 가치, 품질
- ❌ 피함: 혁명적, 최고, 완벽, 절대, 획기적

## 브랜드 메시지

### 메인 메시지
"혁신적인 솔루션으로 더 나은 내일을"

### 서브 메시지
- "당신의 비즈니스를 다음 단계로"
- "기술과 사람을 연결하는 방법"
- "함께 만드는 성공 스토리"

## 비주얼 아이덴티티

### 색상 철학
- **toslab Blue (#0066CC)**: 신뢰, 안정성, 전문성을 상징
- **toslab Orange (#FF6B35)**: 열정, 에너지, 혁신을 표현
- **toslab Green (#00CC66)**: 성장, 성공, 지속가능성을 의미

### 디자인 원칙
1. **명확성**: 복잡함보다는 단순함, 혼란보다는 명확함
2. **일관성**: 모든 터치포인트에서 동일한 경험 제공
3. **접근성**: 누구나 쉽게 이해하고 사용할 수 있도록
4. **현대성**: 트렌드를 반영하되, 시대를 초월하는 디자인

## 고객 경험

### 고객과의 약속
1. **투명성**: 모든 과정을 투명하게 공유합니다
2. **책임감**: 우리의 약속을 지킵니다
3. **지속적 개선**: 끊임없이 더 나은 서비스를 제공합니다

### 터치포인트별 경험

#### 웹사이트
- 첫 방문: 명확한 가치 제안, 쉬운 네비게이션
- 제품 페이지: 상세한 정보, 시각적 자료, 고객 리뷰
- 결제: 간편하고 안전한 프로세스

#### 이메일
- 환영 메시지: 따뜻하고 친근한 톤
- 트랜잭션: 명확하고 정확한 정보
- 마케팅: 가치 있는 콘텐츠 제공

#### 고객 지원
- 빠른 응답 시간
- 친절하고 전문적인 태도
- 문제 해결 지향

## Shopify 스토어 적용 가이드

### 홈페이지 구조
```
┌─────────────────────────────────────┐
│         Hero Section                │
│  • toslab 메인 메시지               │
│  • Primary CTA 버튼 (Blue)          │
│  • Hero 이미지                      │
├─────────────────────────────────────┤
│      주요 가치 (3 columns)          │
│  • 혁신 | 신뢰 | 탁월함              │
├─────────────────────────────────────┤
│      인기 제품                       │
│  • 4-6개 제품 카드                  │
├─────────────────────────────────────┤
│      브랜드 스토리                   │
│  • 텍스트 + 이미지                  │
├─────────────────────────────────────┤
│      고객 후기                       │
│  • 실제 고객 리뷰                   │
├─────────────────────────────────────┤
│      Newsletter Signup              │
│  • CTA + 이메일 입력                │
└─────────────────────────────────────┘
```

### 제품 페이지 요소
- **제품명**: H1, toslab Blue 강조
- **가격**: Large, Bold
- **설명**: 명확하고 간결한 bullet points
- **이미지**: 고품질, 여러 각도
- **CTA 버튼**: toslab Blue, 명확한 문구
- **신뢰 배지**: 배송, 반품 정책

### 컬렉션 페이지
- **필터**: 왼쪽 사이드바, 명확한 카테고리
- **정렬**: 가격, 인기도, 신상품
- **그리드**: 3-4 columns, 반응형
- **제품 카드**: 이미지 + 제품명 + 가격 + Quick View
